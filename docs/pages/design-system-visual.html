System rules

These are now hard rules across the site, not loose style preferences.

Rule 01

Primary CTA is always blue.

Blue fill is the default primary action across hero, cards, bands, and footer CTA surfaces.

Rule 02

Prefer bullets over text blocks.

Inside modules, default to 3-5 bullets before resorting to dense explanatory paragraphs.

Rule 03

Artifacts beat fake UI.

Architecture diagrams, real screenshots, timeline logic, and proof strips outrank decorative dashboard patterns.
