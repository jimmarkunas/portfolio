# Color System — Final

## Primary palette
- Primary blue: `#447ACB`
- Teal: `#1E8E89`
- Amber: `#C7922A`
- Red: `#B54A3A`
- Steel blue support: `#5B78A5`

## Text colors
- Main paragraph text: `#000000`
- Heading / strong UI ink: `#1D2630`
- Secondary support text: `#56606E`

## Background / surface colors
- Page background: `#F4F6F9`
- Panel background: `#FFFFFF`
- Subtle support surface: `#EEF3F8`
- Risk wash: `#F9ECE9`
- Border / line: `#D3DAE3`
- Secondary border / line: `#C2CBD7`

## Dark band range
- Contrast edge: `#1D2E3E`
- Contrast center: `#2B3A49`
- Dark internal card surface: `#314456`

## Callout colors on dark modules
- Callout number blue: `#8AB4FF`
- Primary label text: `#FFFFFF`
- Secondary support text: `rgba(255,255,255,.82)`

## Functional usage

### Blue
Use for:
- logo
- links
- primary CTA
- active states
- micro labels / section identifiers
- select callout numbers

### Teal
Use for:
- stabilization
- positive system change
- operational improvement states

### Amber
Use for:
- awards
- recognition
- milestone emphasis

### Red
Use for:
- blockers
- risk
- pain points
- constraints

### Steel blue
Use for:
- support emphasis
- secondary visual grouping
- architecture / metadata support tones when needed
