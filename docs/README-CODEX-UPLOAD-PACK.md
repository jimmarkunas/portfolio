## What Codex should treat as source of truth

- The system is **light-first**.
- Primary brand blue is **`#447ACB`**.
- Main font is **Inter**.
- Main paragraph text is **black**.
- Primary CTA is **always blue**.
- The site should feel **editorial, premium, sharper-edged, masculine, and consulting-grade**.
- Do **not** drift into generic SaaS dashboard styling.
- Prefer **real artifacts, architecture, timelines, before/after, proof, and bullets** over decorative UI filler.

## What not to trust

Older files outside this pack may contain outdated direction, older color choices, or earlier module ideas that were later rejected.
