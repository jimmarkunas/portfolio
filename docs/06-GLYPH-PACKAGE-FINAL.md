# Glyph Package — Final

## Direction
Use the cleaner centered glyph card style from the approved HTML version.
Glyph cards should be:
- centered
- clean
- minimal
- evenly padded
- not overly editorial-boxy

## Placement
The glyph package should appear at the **very bottom** of the style reference page as an appendix.

## Behavior rules
- Keep stroke weight visually consistent
- Avoid cute or playful icon language
- Favor simple, readable silhouettes
- Use text-based placeholders only where brand glyphs are intentionally represented that way in the approved HTML
