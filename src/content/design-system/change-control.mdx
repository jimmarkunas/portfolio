# Change control rule

## Mandatory rule
Whenever any design-system markup file changes, the graphical display page must be updated in the same change set.

## Files covered
Design-system markup files include:
- `src/content/design-system/design-system-spec.mdx`
- `src/content/design-system/component-inventory.mdx`
- `src/content/design-system/change-control.mdx`

## Graphical file that must be updated
- `src/app/design-system/page.tsx`

## Why
This prevents the written system from drifting away from the rendered visual source.
