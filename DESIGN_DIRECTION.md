# Design Direction

This portfolio uses a Finox-inspired visual system with a controlled blue accent.

Keep:
- portfolio information architecture
- case study structure
- component-based architecture
- Next.js + React + Tailwind + Framer Motion

Replace:
- old Editorial Operator / Aeonik / blue-accent visual language
- ad hoc experimental styling
- conflicting typography systems

Visual goals:
- calm
- premium
- editorial
- spacious
- restrained
- neutral-first
- typography-led

Primary font:
- Inter Display

Accent system:
- accent: #447ACB
- accent-hover: #2F5EA4

Accent usage rules:
- use blue selectively for interaction and emphasis
- use blue for links, inline CTAs, active states, and small moments of focus
- keep the overall system neutral-first
- do not use blue as a dominant page background color
- do not use loud gradients or overly saturated UI

Rules:
- typography-led hierarchy
- subtle dividers
- restrained buttons and chips
- minimal color usage
- light motion only
- no loud gradients
- no heavy shadows
- preserve a calm, premium reading experience
